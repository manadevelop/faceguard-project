# Experiments - FaceGuard

Esta carpeta contiene protocolos para documentar las pruebas finales de la demo.

Escenarios recomendados:

```text
1. rostro real frente a webcam;
2. fotografía impresa;
3. imagen en pantalla de celular;
4. replay de video;
5. baja iluminación;
6. rostro parcial.
```

Registrar por prueba:

```text
- modelo usado;
- threshold;
- score;
- decisión LIVE/SPOOF;
- observaciones del entorno;
- evidencia visual si corresponde.
```
