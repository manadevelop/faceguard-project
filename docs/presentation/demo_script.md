# Guion de demo - FaceGuard

1. Levantar backend FastAPI.
2. Abrir `http://localhost:8000/faceproguard`.
3. Mostrar selector de modelos.
4. Probar rostro real con EfficientNet-B0.
5. Probar foto impresa o imagen en pantalla.
6. Mostrar JSON: score, threshold, modelo, label y decisión.
7. Explicar que los modelos `.pt` fueron entrenados en Colab y copiados al backend.
