Enrolamiento de identidad

Registra un usuario usando el Person ID. Antes de registrar, el sistema puede validar liveness para evitar enrolar un spoof.

1. Iniciar cámaraActiva la webcam desde la sección Verificación.
2. Ingresar Person IDEjemplo: marco, usuario_001, alumno_01.
3. Registrar identidadSe guarda el embedding facial para verificación posterior.
